# CHZZK Live Translator

**[English](README.md) | [한국어](README.ko.md) | 日本語**

[CHZZK（치지직）](https://chzzk.naver.com) のライブ配信やアーカイブの**韓国語音声を、あなたの言語のリアルタイム字幕**に変え、流れてくる**チャットも翻訳**する Chrome 拡張機能です。**Android アプリ（ベータ）**もあります。

## 機能

- 動画プレーヤー上にリアルタイム字幕（英語、日本語、中国語、スペイン語など）
- 各チャットの下に翻訳を表示（ニックネームは翻訳せず、コピペの連投は一度だけ翻訳して「×N」と表示）
- **外国語チャット → 한국어**: 英語・日本語・中国語などで書かれたチャットを韓国語に翻訳（韓国の視聴者や配信者向け、標準はオフ）
- **ステライブ用語集を内蔵**: メンバー名・ファンネーム・挨拶・ミームの英語版と日本語版を入れてあるので、Whisper が名前を正しく書き取り、翻訳の表記もそろいます（High accuracy モードと Android アプリ、標準でオン）
- **配信タイトルの翻訳**: タイトルのすぐ下に翻訳を表示（ライブ・アーカイブ）
- ライブ配信とアーカイブの両方に対応
- [Android アプリ（ベータ）](#android-アプリベータ): **公式 CHZZK アプリの上に**字幕とチャット翻訳を表示
- 2つのモード:

| モード | 音声認識 | 翻訳 | APIキー | 制限 |
|---|---|---|---|---|
| **Free**（標準） | Chrome 内蔵の音声認識 | Chrome 内蔵の翻訳 | 不要 | なし |
| **High accuracy** | Whisper large-v3（Groq 無料枠） | NVIDIA AI（任意）または Chrome の翻訳 | 自分の無料 Groq キー（NVIDIA キーは任意） | Whisper は1日約8時間。超えると自動で Free モードに切り替わります |

まず **Free** で試してください。字幕の取りこぼしが多い場合（早口、ゲーム音、不明瞭な発音）は **High accuracy** に切り替えます。

## 必要なもの

- PC 版 Google Chrome 138 以上（Free モードは Chrome 内蔵の翻訳機能を使います）
- Android スマートフォンでは [Android アプリ（ベータ）](#android-アプリベータ)を使ってください。iPhone / iPad には対応していません。

## インストール（Chrome 拡張機能）

Chrome ウェブストアを使わず、自分で読み込む方式です。1分ほどで終わります。

1. **ダウンロード**: [最新リリース](https://github.com/pst10101/chzzk-live-translator/releases/latest)を開き、*Assets* の拡張機能の zip **`chzzk-live-translator-v1.x.x.zip`** をクリックします（数字はもっと新しい場合があります）。
2. **解凍**: zip を右クリック →「**すべて展開**」（Windows）、またはダブルクリック（Mac）。フォルダは `ドキュメント` など**消さない場所**に置いてください。Chrome は毎回このフォルダから拡張機能を読むので、あとから**削除したり移動したりしないでください**。
3. Chrome のアドレスバーに **`chrome://extensions`** と入力して開きます。
4. 右上の**デベロッパー モード**をオンにします。
5. 左上の「**パッケージ化されていない拡張機能を読み込む**」をクリックし、解凍したフォルダ（`manifest.json` が直接入っているフォルダ）を選びます。中にフォルダがもう1つだけある場合は、そのフォルダを選んでください。
6. 一覧に **CHZZK Live Translator** が表示されます。ツールバーのパズルのアイコン → この拡張機能を**ピン留め**します。

> すでに開いていた CHZZK のタブは、一度更新してください。

**アップデート**: 新しい zip をダウンロードして古いフォルダのファイルを上書きし、`chrome://extensions` の拡張機能カードにある丸い矢印（更新）を押します。

**うまくいかないとき**: 「マニフェスト ファイルが見つからないか、読み取れません」と出たら、フォルダの選び間違いです（1つ内側か外側のフォルダを選んでください）。「パッケージ化されていない拡張機能を読み込む」が見えないときは、デベロッパー モードがオフです。

## 使い方（Free モード）

1. CHZZK のライブ配信を開き、音が出る状態で再生します。
2. 拡張機能のアイコンをクリック → **Free** のまま → **Translate into** で言語を選びます。
3. **Start live subtitles** をクリックします。
4. 初回は Chrome が翻訳機能をダウンロードすることがあります。プレーヤー上に *「Click here to download the free … translator」* と出たら、一度クリックしてください。

話している間は韓国語が灰色で表示され、文が終わると翻訳に変わります。チャットと配信タイトルは自動で翻訳されます（止めるには **Translate chat & title** をオフに）。

**外国語のチャットを韓国語に**翻訳したい場合は **Foreign chat → 한국어** をオンにします。この翻訳は緑色で表示されます。Free モードでは初回に一度、プレーヤー上の案内をクリックして韓国語への翻訳機能をダウンロードする必要がある場合があります。

## Android アプリ（ベータ）

Android スマートフォン用の別アプリです。配信は **公式 CHZZK アプリ**（またはブラウザ）でそのまま見て、翻訳はその上に重ねて表示されます。

- **音声 → 字幕**: 映像の上に字幕を表示します（お好みで韓国語の原文も下に表示）。
- **画面のチャット → 自分の言語**: チャットの場所を指定すると、アプリが読み取って小さなパネルに翻訳を表示します。画面の画像は**スマートフォンの中だけ**で読み取り（Google ML Kit の文字認識）、アップロードしません。翻訳に送るのは認識したチャットの文字だけです。
- どちらもアプリ内、または浮かんでいる **CC** ボタンから個別にオン／オフできます。

- Android 10 以上
- **無料の Groq キーが必須**です（[Groq キー](#groq-キー音声認識-high-accuracy-に必須)を参照）。NVIDIA キーは任意で、入れると Groq の無料枠に余裕ができます。スマートフォンには Free モードはありません（Chrome 内蔵の音声認識・翻訳はアプリから使えないため）。
- Play ストアではなく APK ファイルを直接インストールします。少数の端末でしか確認していない**ベータ版**なので、問題があれば [Issues](https://github.com/pst10101/chzzk-live-translator/issues) で教えてください。

### インストール

1. スマートフォンで[最新リリース](https://github.com/pst10101/chzzk-live-translator/releases/latest)を開き、**`chzzk-live-translator-android-v1.x.x.apk`** をダウンロードします。
2. ダウンロードしたファイルを開きます。この提供元（ブラウザやファイルアプリ）からのインストールを許可するか聞かれたら許可し、戻って**インストール**をタップします。Play プロテクトが不明なアプリと警告したら、**詳細 → インストールする**をタップします。
3. **CHZZK Live Translator** を開き、**Groq キー**を貼り付けて、**翻訳先の言語**と**翻訳するもの**（音声、チャット、または両方）を選びます。

### 使い方

1. **▶ 翻訳を開始**をタップし、Android が求める 2 つの許可を与えます。
   - **他のアプリの上に重ねて表示** — CHZZK アプリの上に字幕、チャットパネル、CC ボタンを出すため。
   - **画面の録画** — 配信の音声を聞き、チャット翻訳がオンならチャット範囲を読み取るため。録画・保存はしません。
2. CHZZK アプリで配信を開きます（**CHZZK ↗** ボタンですぐ開けます）。話してから数秒で字幕が出ます。
3. チャット: 浮かんでいる **CC** ボタン → **チャット範囲…** をタップします。**青い枠**をチャットの上に、**緑の枠**を翻訳を出したい場所にドラッグし、角をドラッグして大きさを合わせたら**保存**します。縦画面と横画面は別々に保存されます。
4. 見終わったら **CC → ■ 停止**（または通知の**停止**）をタップします。

- 視聴中も CC メニューで字幕とチャット翻訳をオン／オフでき、ボタンはどこへでもドラッグで移動できます。
- アプリの設定では、文字の大きさ、字幕の高さ、Whisper のタイミング、ステライブ用語集、自分の名前・用語も変えられます。
- Groq の無料枠: Whisper は 1 日約 8 時間、翻訳モデルはモデルごとに 1 日 1,000 回です。上限に達すると画面に表示し、リセットされると再開します。NVIDIA キーを入れるとかなり余裕ができます。
- オンの間は他のアプリの音も拾うことがあるので、見終わったら止めてください。

## APIキーの取得（High accuracy モード）

どちらのキーも無料で、クレジットカードは不要です。**重要なのは Groq** で、これで認識精度が大きく上がります。NVIDIA は任意です。

### Groq キー（音声認識）— High accuracy に必須

1. **https://console.groq.com** にアクセスし、メール、Google、または GitHub で登録します。
2. 左のメニューから **API Keys** を開きます。
3. **Create API Key** を押し、好きな名前（例: `chzzk-translator`）を付けて作成します。
4. **キーはすぐにコピーしてください。** `gsk_` で始まり、表示されるのは一度だけです。なくした場合は、削除して新しく作り直します。

無料枠の制限: アカウントごとに1日 2,000 リクエスト、音声 8 時間。ポップアップの **Whisper timing** で使い方を選べます。

| Whisper timing | 字幕の遅れ | 1日の Whisper 時間 |
|---|---|---|
| **All day**（標準） | 約15秒 | 約8時間 |
| **Fast** | 約5〜10秒 | 約3〜5時間 |

無料枠を使い切ると、拡張機能が**自動で Chrome の無料音声認識（Free モード）に切り替わり**、制限がリセットされると Whisper に戻ります。字幕が止まることはありません。

### NVIDIA キー（AI 翻訳）— 任意

キーがなければ Chrome 内蔵の翻訳を使います。あれば、スラングやネットミームもより自然に翻訳できます。

1. **https://build.nvidia.com** にアクセスし、サインインするか NVIDIA アカウントを作成します。
2. 任意のモデルのページ（例: *llama-3.3-70b-instruct*）を開き、**Get API Key** → **Generate Key** をクリックします。
3. 初回は **SMS による電話番号の確認**を求められます。リストにない国もあります。自分の国がなければ、NVIDIA は使わなくて大丈夫です。
4. `nvapi-` で始まるキーをコピーします。

無料枠の制限: 1分あたり約40リクエスト。字幕の翻訳が優先され、チャットが非常に速いときは新しいメッセージから翻訳します。

### キーを拡張機能に入れる

1. 拡張機能のアイコンをクリック → **High accuracy** を選びます。
2. **API keys & models** を開き、Groq キー（あれば NVIDIA キーも）を貼り付けます。
3. **Test keys** をクリックし、✓ が出ることを確認します。
4. **Start live subtitles** をクリックします。

### キーを安全に保つ

- キーは**あなた自身の Chrome の中だけ**（`chrome.storage.local`）に保存されます。このプロジェクトのコードには含まれていません。
- キーをコード、コミット、Issue、スクリーンショットに**絶対に載せないでください**。持っている人は誰でもあなたの無料枠を使い切れます。
- キーが漏れたら、Groq コンソール / NVIDIA のサイトで削除し、新しく作り直してください。

## ヒント

- **名前と用語**（*API keys & models* 内）: 配信者の名前やよく出る言葉を1行に1つずつ書きます。訳し方も添えられます。

  ```
  멤버이름 = Member Name
  별명 = あだ名 | 誰・何なのかの説明（AI 用のメモ、画面には出ません）
  자주 쓰는 말 = how to translate it
  ```

  Whisper が名前を正しく書き取りやすくなり、翻訳の表記もそろいます。
- **Built-in StelLive terms**（*API keys & models* 内のスイッチ、標準でオン）: ステライブのメンバー名・ファンネーム・挨拶・ミームを自動で追加します。日本語に翻訳するときは日本語版、それ以外は英語版を使います（その他の言語では公式の名前表記だけを固定）。自分で書いた *Names & terms* が優先されます。他の配信者を見るときはオフにしてください。一覧は [`glossary/`](glossary) にあります。
- **字幕を動かす**: 動画の上で字幕をドラッグすれば好きな位置に動かせて、位置は記憶されます。ポップアップの **Subtitle position → move** は、誰も話していないときにドラッグ用のサンプル行を表示します。**reset** で下の標準位置に戻ります。
- **字幕サイズ**と **Show Korean under subtitles** はポップアップにあります。

## よくある質問

**なぜ全員が自分の Groq キーを用意するのですか？**
Groq のアカウントごとに無料枠があります。自分のキーを使えば、自分の視聴は自分の枠だけを使い、サーバーも要らず誰にも費用がかかりません。1つのキーを大勢で共有すると、数分で使い切ってしまいます。

**本当に無料ですか？**
はい。Free モードは何も要りません。High accuracy は Groq と NVIDIA の無料枠を使い、この拡張機能に支払い情報を入力することはありません。

**スマートフォンで使えますか？**
Android なら使えます。[Android アプリ（ベータ）](#android-アプリベータ)をインストールしてください。iPhone / iPad には対応していません。

## プライバシー

- Free モード: 配信の音声は Chrome の音声認識サービスに送られ、翻訳はあなたのコンピューターで行われます。
- High accuracy モード: 配信の音声は Groq に送られ、NVIDIA キーを入れた場合はテキストが NVIDIA に送られます。
- Android アプリ: 配信の音声は Groq に送られ、テキスト（字幕の文と認識したチャットの文字）は NVIDIA キーがあれば NVIDIA に、なければ Groq に送られます。チャット範囲はスマートフォンの中で画面を読み取って処理し、画面の画像はどこにも送りません。キーはスマートフォンのアプリ内にだけ保存されます。
- それ以外にはどこにも送信せず、拡張機能もアプリもデータを収集しません。

## トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「Reload the CHZZK page once」 | CHZZK のタブを更新して、もう一度開始する |
| Free モードで字幕が出ない | 配信が再生中か確認。プレーヤーがミュートなら音量を少し上げる。Chrome を更新する |
| 「Click here to start free subtitles」 | そのメッセージを一度クリックする |
| 韓国語だけで翻訳が出ない | Free: 翻訳機能のダウンロード表示をクリックするか、別の言語を選ぶ。High accuracy: NVIDIA キーを確認するか、削除して Chrome の翻訳を使う |
| 翻訳モデルが見つからない | *API keys & models* で **load list** をクリックし、別のモデルを選ぶ |
| チャットが翻訳されない | CHZZK がページのレイアウトを変えた可能性があります。`content.js` の `TEXT_SEL` を更新してください |
| Android: 字幕が出ない／「音声をキャプチャできませんでした」 | 配信が音付きで再生中か確認して、もう一度開始。共有する範囲を聞かれたら**画面全体**を選ぶ。音声のキャプチャを許可しないアプリもあります |
| Android: 韓国語しか出ない／「翻訳エラー（404）」 | アプリを v1.1.0 以降に更新（古い版が使っていた Groq の翻訳モデルが終了したため） |
| Android: チャットが翻訳されない | CC → **チャット範囲…** で青い枠をチャットの行にぴったり合わせる／CC メニューでチャット翻訳がオンか確認 |
| Android: APK をインストールできない | ブラウザやファイルアプリからのインストールを許可する。Android 10 以上が必要 |

## 開発者向け

| ファイル | 役割 |
|---|---|
| `manifest.json` | 拡張機能のマニフェスト（Manifest V3） |
| `popup.*` | 設定ポップアップ |
| `engine-main.js` | Free エンジン（ページ内で動作）: 動画の音声 → Chrome の音声認識、Chrome の翻訳 |
| `content.*` | 字幕オーバーレイ、チャット翻訳、エンジンとの橋渡し |
| `background.js` | High accuracy: キャプチャの開始/停止、NVIDIA 翻訳、使用量カウンター |
| `offscreen.*`, `pcm-worklet.js` | High accuracy: タブ音声のキャプチャ、無音で区切って Groq に送信 |
| `audio-utils.js` | リサンプリング、音声の分割、WAV エンコード、幻覚（ハルシネーション）フィルター |
| `translate-utils.js` | 翻訳プロンプトとレスポンスの解析 |
| `glossary/` | ステライブ用語集（`stellive-en.txt`, `stellive-ja.txt`）。Android アプリと共通 |
| `chat-utils.js` | どのチャットをどの方向に翻訳するかの判定 |
| `android/` | Android アプリ（Java。チャットの読み取りは Google ML Kit の文字認識で端末内処理）。ビルド: JDK 17 + Android SDK 34 を入れて `android/` で `gradle assembleDebug` |
