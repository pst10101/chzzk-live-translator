# CHZZK Live Translator

**[English](README.md) | 한국어 | [日本語](README.ja.md)**

[치지직](https://chzzk.naver.com) 라이브와 다시보기의 **한국어 음성을 실시간 자막**으로 바꾸고, **채팅을 원하는 언어로 번역**해 주는 크롬 확장 프로그램입니다. 이제 **안드로이드 앱(베타)** 도 있습니다.

![번역 예시: 공식 치지직 앱 위에 안드로이드 앱이 띄운 영어 자막 (아래는 한국어 원문)](docs/android-subtitles.jpg)

> **안내 / 면책**
> - 개인과 팬 용도로 만든 **비공식·비영리 팬 프로젝트**입니다. 네이버, 치지직, 스텔라이브, 스트리머와 관련이 없고, 공식 승인을 받은 것도 아닙니다. 모든 이름과 상표는 각 소유자의 것입니다.
> - 방송을 다운로드, 녹화, 저장, 재업로드하지 않습니다. 보고 있는 페이지의 소리와 채팅만 사용하고(짧은 소리 조각은 내가 고른 음성 인식 서비스로 보내집니다. 개인정보 항목 참고), 번역은 **내 화면에만** 보여 줍니다.
> - 사용에 따른 책임은 사용자에게 있습니다. 번역이 틀릴 수 있고, 아무 보증 없이 "있는 그대로" 제공됩니다 ([LICENSE](LICENSE) 참고).
> - 네이버/치지직, 권리자, 스트리머가 문제를 제기하면 Issues로 알려 주세요. 바로 수정하거나 **삭제**하겠습니다.

*AI 어시스턴트 [Claude](https://claude.ai)(Anthropic)의 도움으로 만들었습니다.*

## 기능

- 영상 위에 실시간 자막 (영어, 일본어, 중국어, 스페인어 등)
- 채팅 메시지 아래에 번역 표시 (닉네임은 번역하지 않고, 같은 문구 도배는 한 번만 번역해서 "×N" 으로 표시)
- **외국어 채팅 → 한국어**: 영어, 일본어, 중국어 등으로 쓴 채팅을 한국어로 번역 (한국 시청자나 스트리머용, 기본은 꺼짐)
- **스텔라이브 용어집 내장**: 멤버 이름·팬네임·인사말·밈을 영어판·일본어판으로 넣어 둬서 Whisper가 이름을 정확히 받아 적고 번역도 일관되게 나옴 (High accuracy 모드와 안드로이드 앱, 기본으로 켜짐)
- **방송 제목 번역**: 제목 바로 아래에 번역 표시 (라이브·다시보기)
- 라이브와 다시보기 모두 지원
- [안드로이드 앱(베타)](#안드로이드-앱-베타): **공식 치지직 앱 위에** 자막과 채팅 번역을 띄움
- 두 가지 모드

| 모드 | 음성 인식 | 번역 | API 키 | 한도 |
|---|---|---|---|---|
| **Free** (기본) | 크롬 내장 음성 인식 | 크롬 내장 번역기 | 필요 없음 | 없음 |
| **High accuracy** | Whisper large-v3 (Groq 무료) | 엔비디아 AI(선택) 또는 크롬 번역기 | 내 무료 Groq 키, 엔비디아 키는 선택 | Whisper 하루 약 8시간, 이후 Free 모드로 자동 전환 |

먼저 **Free** 로 써 보고, 말이 빠르거나 게임 소리가 크거나 발음이 뭉개져서 자막이 자주 빠지면 **High accuracy** 로 바꾸세요.

## 필요한 것

- PC용 구글 크롬 138 이상 (Free 모드가 크롬 내장 번역기를 씀)
- 안드로이드 폰에서는 [안드로이드 앱(베타)](#안드로이드-앱-베타)을 쓰세요. 아이폰·아이패드는 지원하지 않습니다.

## 설치 (크롬 확장)

크롬 웹스토어 없이 직접 불러오는 방식이에요. 1분 정도 걸립니다.

1. **다운로드**: [최신 릴리스](https://github.com/pst10101/chzzk-live-translator/releases/latest)에서 *Assets* 아래의 확장 zip **`chzzk-live-translator-v1.x.x.zip`** 을 클릭 (숫자는 더 높을 수 있음)
2. **압축 풀기**: zip 우클릭 → **모두 압축 풀기** (윈도우) / 더블클릭 (맥). 폴더는 `문서` 같은 **지우지 않을 곳**에 두세요. 크롬이 매번 이 폴더에서 확장을 읽기 때문에 **나중에 삭제하거나 옮기면 안 됩니다**.
3. 크롬 주소창에 **`chrome://extensions`** 입력
4. 오른쪽 위 **개발자 모드** 켜기
5. 왼쪽 위 **압축해제된 확장 프로그램을 로드합니다** 클릭 → 압축 푼 폴더 선택 (`manifest.json` 이 바로 들어 있는 폴더. 안에 폴더가 하나 더 있으면 그 폴더를 선택)
6. 목록에 **CHZZK Live Translator** 가 생깁니다. 툴바의 퍼즐 아이콘 → 이 확장 **고정**

> 이미 열려 있던 치지직 탭은 새로고침을 한 번 해 주세요.

**업데이트**: 새 zip을 받아 기존 폴더 파일을 덮어쓰고, `chrome://extensions` 의 확장 카드에서 둥근 화살표(새로고침)를 누르세요.

**안 될 때**: "매니페스트 파일이 없거나 읽을 수 없습니다" 는 폴더를 잘못 고른 것입니다 (한 단계 안쪽이나 바깥쪽 폴더 선택). "압축해제된 확장 프로그램을 로드합니다" 버튼이 안 보이면 개발자 모드가 꺼져 있는 것입니다.

## 사용법 (Free 모드)

1. 치지직 라이브를 열고 소리가 나오는 상태로 재생합니다.
2. 확장 아이콘 → **Free** 그대로 → **Translate into** 에서 언어 선택
3. **Start live subtitles** 클릭
4. 처음 한 번은 크롬이 번역기를 내려받아야 할 수 있습니다. 영상 위에 *"Click here to download the free … translator"* 가 뜨면 한 번 클릭하세요.

말하는 동안 한국어가 회색으로 실시간 표시되고, 문장이 끝나면 번역으로 바뀝니다. 채팅과 방송 제목은 자동으로 번역됩니다. (끄려면 **Translate chat & title** 해제)

**외국어로 쓴 채팅을 한국어로** 보고 싶으면 **Foreign chat → 한국어** 를 켜세요. 이 번역은 초록색으로 표시됩니다. Free 모드에서는 처음 한 번 영상 위 안내 문구를 클릭해 한국어 번역기를 내려받아야 할 수 있습니다.

## 안드로이드 앱 (베타)

안드로이드 폰용 별도 앱입니다. 방송은 **공식 치지직 앱**(또는 브라우저)에서 그대로 보고, 번역기는 그 위에 떠서 작동합니다.

- **음성 → 자막**: 영상 위에 자막을 띄웁니다 (원하면 한국어 원문도 아래에 표시).
- **화면 속 채팅 → 내 언어**: 채팅이 있는 곳을 지정하면 앱이 읽어서 작은 패널에 번역을 보여 줍니다. 화면 이미지는 **폰 안에서만** 읽고(Google ML Kit 글자 인식) 업로드하지 않습니다. 인식한 채팅 글자만 번역용으로 보냅니다.
- 둘 다 앱에서, 또는 떠 있는 **CC** 버튼에서 각각 켜고 끌 수 있습니다.

- 안드로이드 10 이상
- **무료 Groq 키가 꼭 필요합니다** ([Groq 키](#groq-키-음성-인식--high-accuracy-에-필수) 참고). 엔비디아 키는 선택이고, 넣으면 Groq 무료 한도 부담이 줄어듭니다. 폰에는 Free 모드가 없습니다 (크롬 내장 음성 인식·번역기를 앱에서 쓸 수 없음).
- 플레이 스토어 앱이 아니라 APK 파일을 직접 설치합니다. 몇 개 기기에서만 확인한 **베타**라서, 문제가 있으면 [Issues](https://github.com/pst10101/chzzk-live-translator/issues)로 알려 주세요.

### 설치

1. 폰에서 [최신 릴리스](https://github.com/pst10101/chzzk-live-translator/releases/latest)를 열고 **`chzzk-live-translator-android-v1.x.x.apk`** 를 내려받습니다.
2. 받은 파일을 엽니다. 안드로이드가 이 출처(브라우저나 파일 앱)에서 앱 설치를 허용할지 물으면 허용하고, 뒤로 가서 **설치**를 누릅니다. Play 프로텍트가 알 수 없는 앱이라고 경고하면 **세부정보 더보기 → 무시하고 설치**를 누르세요.
3. **CHZZK Live Translator** 를 열고 **Groq 키**를 붙여넣은 뒤, **번역할 언어**와 **번역할 것**(음성, 채팅, 또는 둘 다)을 고릅니다.

### 사용법

1. **▶ 번역 시작**을 누르고 안드로이드가 묻는 두 가지를 허용합니다.
   - **다른 앱 위에 표시**: 치지직 앱 위에 자막, 채팅 패널, CC 버튼을 띄우는 데 씁니다.
   - **화면 녹화**: 방송 소리를 듣고, 채팅 번역을 켰다면 채팅 영역을 읽는 데 씁니다. 아무것도 녹화·저장하지 않습니다.
2. 치지직 앱에서 방송을 엽니다 (**치지직 ↗** 버튼으로 바로 열 수 있음). 말하고 몇 초 뒤 자막이 나옵니다.
3. 채팅: 떠 있는 **CC** 버튼 → **채팅 영역…** 을 누릅니다. **파란 상자**를 채팅 위로, **초록 상자**를 번역을 띄울 곳으로 끌어다 놓고, 모서리를 끌어 크기를 맞춘 뒤 **저장**합니다. 세로·가로 화면은 따로 저장됩니다.
4. 다 보면 **CC → ■ 중지** (또는 알림의 **중지**)를 누릅니다.

- 보는 중에도 CC 메뉴에서 자막과 채팅 번역을 켜고 끌 수 있고, 버튼은 아무 데로나 끌어서 옮길 수 있습니다.
- 앱 설정에서 글자 크기, 자막 높이, Whisper 타이밍, 스텔라이브 용어집, 내 이름·용어도 바꿀 수 있습니다.
- Groq 무료 한도: Whisper는 하루 약 8시간, 번역 모델은 모델당 하루 1,000번입니다. 한도에 닿으면 화면에 알려 주고, 초기화되면 다시 이어집니다. 엔비디아 키를 넣으면 훨씬 여유롭습니다.
- 켜져 있는 동안 다른 앱의 소리도 잡힐 수 있으니 다 보면 꺼 주세요.

## API 키 받는 법 (High accuracy 모드)

두 키 모두 무료이고 카드 등록이 필요 없습니다. **중요한 건 Groq 키**입니다. 인식 정확도를 크게 올려 주는 게 Groq이고, 엔비디아는 없어도 됩니다.

### Groq 키 (음성 인식) — High accuracy 에 필수

1. **https://console.groq.com** 에 들어가 이메일, 구글 또는 깃허브 계정으로 가입합니다.
2. 왼쪽 메뉴에서 **API Keys** 를 엽니다.
3. **Create API Key** 를 누르고 이름을 아무거나 적은 뒤 (예: `chzzk-translator`) 만듭니다.
4. **키를 바로 복사하세요.** `gsk_` 로 시작하고 **한 번만 보여 줍니다.** 잃어버리면 지우고 새로 만들면 됩니다.

무료 한도: 계정마다 하루 요청 2,000번, 음성 8시간. 팝업의 **Whisper timing** 설정으로 어떻게 쓸지 고를 수 있습니다.

| Whisper timing | 자막 지연 | 하루 Whisper 사용 |
|---|---|---|
| **All day** (기본) | 약 15초 | 약 8시간 |
| **Fast** | 약 5~10초 | 약 3~5시간 |

무료 한도를 다 쓰면 **자동으로 크롬 무료 음성 인식(Free 모드)으로 넘어가고**, 한도가 초기화되면 다시 Whisper로 돌아옵니다. 자막이 끊기지 않습니다.

### 엔비디아 키 (AI 번역) — 선택

이 키가 없으면 크롬 내장 번역기로 번역합니다. 넣으면 인터넷 말투나 밈을 더 자연스럽게 번역합니다.

1. **https://build.nvidia.com** 에 들어가 로그인하거나 엔비디아 계정을 만듭니다.
2. 아무 모델 페이지나 열고 (예: *llama-3.3-70b-instruct*) **Get API Key** → **Generate Key** 를 누릅니다.
3. 처음 한 번은 **휴대폰 문자 인증**을 요구합니다. 목록에 없는 나라도 있는데, 그럴 땐 엔비디아는 건너뛰면 됩니다.
4. `nvapi-` 로 시작하는 키를 복사합니다.

무료 한도: 분당 약 40번. 자막을 먼저 번역하고, 채팅이 아주 빠를 때는 최신 채팅부터 번역합니다.

### 확장에 키 넣기

1. 확장 아이콘 → **High accuracy** 선택
2. **API keys & models** 를 열고 Groq 키 (있으면 엔비디아 키도) 붙여넣기
3. **Test keys** 를 눌러 ✓ 확인
4. **Start live subtitles** 클릭

### 키 안전하게 쓰기

- 키는 **내 크롬 안에만** 저장됩니다 (`chrome.storage.local`). 이 프로젝트 코드에는 들어 있지 않습니다.
- 키를 코드, 커밋, 이슈, 스크린샷에 **절대 올리지 마세요.** 키를 가진 사람은 누구나 내 무료 한도를 써 버릴 수 있습니다.
- 키가 유출되면 Groq 콘솔 / 엔비디아 사이트에서 지우고 새로 만드세요.

## 팁

- **Names & terms** (*API keys & models* 안): 스트리머 이름이나 자주 쓰는 말을 한 줄에 하나씩 적고, 원하면 번역도 지정할 수 있습니다.

  ```
  멤버이름 = Member Name
  별명 = Nickname | 누구/무엇인지 설명 (AI 참고용, 화면엔 안 나옴)
  자주 쓰는 말 = 이렇게 번역해줘
  ```

  Whisper가 이름을 정확히 받아 적고, 번역도 일관되게 나옵니다.
- **Built-in StelLive terms** (*API keys & models* 안의 스위치, 기본으로 켜짐): 스텔라이브 멤버 이름·팬네임·인사말·밈을 자동으로 넣어 줍니다. 일본어로 번역할 땐 일본어판, 그 외엔 영어판을 씁니다 (다른 언어는 공식 이름 표기만 고정). 직접 적은 *Names & terms* 가 먼저 적용되고, 다른 스트리머를 볼 땐 꺼 두세요. 목록은 [`glossary/`](glossary) 폴더에 있습니다.
- **자막 옮기기**: 영상 위 자막을 마우스로 끌어서 원하는 곳에 두면 그 위치를 기억합니다. 아무도 말하지 않을 때는 팝업의 **Subtitle position → move** 를 누르면 끌어 볼 수 있는 예시 자막이 뜨고, **reset** 을 누르면 다시 아래 가운데로 돌아갑니다.
- **Subtitle size**(자막 크기), **Show Korean under subtitles**(한국어 같이 보기)는 팝업에서 바꿀 수 있습니다.

## 자주 묻는 질문

**왜 각자 Groq 키를 받아야 하나요?**
Groq 무료 한도는 계정마다 따로 있습니다. 각자 자기 키를 쓰면 내가 본 만큼만 내 한도에서 빠지고, 이 프로젝트는 서버도 비용도 필요 없습니다. 키 하나를 여러 명이 같이 쓰면 몇 분 만에 한도가 끝납니다.

**정말 무료인가요?**
네. Free 모드는 아무것도 필요 없고, High accuracy 는 Groq·엔비디아 무료 한도만 씁니다. 이 확장에 결제 정보를 넣을 일은 없습니다.

**휴대폰에서도 되나요?**
안드로이드는 됩니다. [안드로이드 앱(베타)](#안드로이드-앱-베타)을 설치하세요. 아이폰·아이패드는 지원하지 않습니다.

## 개인 정보

- Free 모드: 방송 소리는 크롬 음성 인식 서비스로 가고, 번역은 내 PC 안에서 처리됩니다.
- High accuracy 모드: 방송 소리는 Groq로 가고, 엔비디아 키를 넣었다면 글은 엔비디아로 갑니다.
- 안드로이드 앱: 방송 소리는 Groq로 가고, 글(자막 문장과 인식한 채팅 글자)은 엔비디아 키가 있으면 엔비디아로, 없으면 Groq로 갑니다. 채팅 영역은 폰 안에서 화면을 읽어 처리하고, 화면 이미지는 어디로도 보내지 않습니다. 키는 폰의 앱 안에만 저장됩니다.
- 그 밖의 곳으로는 아무것도 보내지 않고, 확장과 앱 모두 어떤 정보도 모으지 않습니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| "Reload the CHZZK page once" | 치지직 탭 새로고침 후 다시 시작 |
| Free 모드에서 자막이 안 뜸 | 방송이 재생 중인지 확인 / 플레이어를 음소거했다면 볼륨을 조금 올리기 / 크롬 업데이트 |
| "Click here to start free subtitles" | 그 문구를 한 번 클릭 |
| 한국어만 뜨고 번역이 안 됨 | Free: 번역기 다운로드 문구 클릭 또는 다른 언어 선택 / High accuracy: 엔비디아 키 확인, 또는 키를 지워서 크롬 번역기 사용 |
| Translation model not found | *API keys & models* 에서 **load list** 를 눌러 다른 모델 선택 |
| 채팅이 번역 안 됨 | 치지직 화면 구조가 바뀌었을 수 있음 → `content.js` 의 `TEXT_SEL` 수정 |
| 안드로이드: 자막이 안 나옴 / "소리를 캡처하지 못했어요" | 방송이 소리와 함께 재생 중인지 확인하고 다시 시작. 무엇을 공유할지 물으면 **전체 화면** 선택. 소리 캡처를 막는 앱도 있음 |
| 안드로이드: 한국어만 나옴 / "번역 오류 (404)" | 앱을 v1.1.0 이상으로 업데이트 (예전 버전이 쓰던 Groq 번역 모델이 종료됨) |
| 안드로이드: 채팅이 번역 안 됨 | CC → **채팅 영역…** 에서 파란 상자를 채팅 줄 위에 정확히 맞추기 / CC 메뉴에서 채팅 번역이 켜져 있는지 확인 |
| 안드로이드: APK 설치가 안 됨 | 브라우저나 파일 앱의 설치 허용을 켜기. 안드로이드 10 이상만 지원 |

## 개발자용

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 설정 (Manifest V3) |
| `popup.*` | 설정 팝업 |
| `engine-main.js` | Free 엔진 (페이지 안에서 실행): 영상 소리 → 크롬 음성 인식, 크롬 번역기 |
| `content.*` | 자막 표시, 채팅 번역, 엔진 연결 |
| `background.js` | High accuracy: 캡처 시작/정지, 엔비디아 번역, 사용량 집계 |
| `offscreen.*`, `pcm-worklet.js` | High accuracy: 탭 소리 캡처 → 말 끊기는 곳에서 잘라 Groq로 전송 |
| `audio-utils.js` | 리샘플링, 음성 구간 자르기, WAV 변환, 환각 문구 필터 |
| `translate-utils.js` | 번역 프롬프트와 응답 정리 |
| `glossary/` | 스텔라이브 용어집 (`stellive-en.txt`, `stellive-ja.txt`), 안드로이드 앱과 공유 |
| `chat-utils.js` | 어떤 채팅을 어느 방향으로 번역할지 판단 |
| `android/` | 안드로이드 앱 (Java, 채팅 읽기는 Google ML Kit 글자 인식으로 폰 안에서 처리). 빌드: JDK 17 + Android SDK 34 설치 후 `android/` 에서 `gradle assembleDebug` |
